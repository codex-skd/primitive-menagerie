<h2>v0.0.0-beta.1 - First release: Primitive Mobs on NeoForge 1.21.1</h2>

<p>First public build of <strong>Primitive Menagerie</strong>, a NeoForge 1.21.1 port of <strong>Primitive Mobs</strong> 1.2.3 by Daveyx0 (CC BY-NC 3.0). <strong>The original work has been modified.</strong> Requires <strong>Mobweave Core</strong>.</p>

<h3>Features</h3>
<ul>
<li><strong>26 creatures</strong>: 19 hostile (skeleton warrior, rocket, festive and support creepers, spider family, goblin, harpy, treasure and brain slimes, haunted tool, bewitched tome, blazing juggernaut, lily lurker, trollager, mimic, flame spewer, void eye, yeti) and 7 passive or neutral (chameleon, dodo, filch lizard, grove sprite, lost miner, sheepman, traveling merchant), each with a spawn egg.</li>
<li><strong>Items</strong>: camouflage armour that follows the block colour, camouflage dye, goblin mace, wonder sap, dodo and spider eggs, mystery eggs, dodo meat and the mimic orb.</li>
<li><strong>9 recipes</strong>, including the camouflage toggle and the wonder sap conversion.</li>
<li><strong>Villager professions and trades</strong> for the Lost Miner, Sheepman and Traveling Merchant.</li>
<li><strong>Mimic chests</strong> generated in caves, plus the mimic orb.</li>
<li><strong>Spawning</strong> through Mobweave Core (29 entries), with a per-creature enable toggle and special settings in the config.</li>
<li>Textures, sounds, loot tables and translations (English, Spanish, Japanese, Russian, Turkish and Chinese).</li>
</ul>

<h3>Technical Changes</h3>
<ul>
<li>Ported from Forge 1.12.2 to NeoForge 21.1.249 (Minecraft 1.21.1, Java 21) on top of Mobweave Core. Own id <code>primitive_menagerie</code>.</li>
<li>Models rebuilt for the 1.21 model system; item NBT became data components; networking uses custom payloads; special recipes are custom recipes.</li>
<li>Not ported: Dynamic Trees and Just Enough Resources integrations and the Forge config GUI. The Yeti, which the original never registered, is available.</li>
</ul>
