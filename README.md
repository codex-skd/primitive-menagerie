# Primitive Menagerie

A NeoForge 1.21.1 port of **Primitive Mobs**: a menagerie of familiar, sometimes goofy creatures such as skeleton
warriors, haunted tools, support creepers, treasure slimes, mimics, goblins, yetis, a dodo, a traveling merchant and
many more.

> **Status: in development.** See `docs/PLAN_PORT.md` (Spanish, internal).
